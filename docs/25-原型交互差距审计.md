## 1. 界面布局差距

### 1.1 现状

- 侧栏 220px（可收 56），分组 工作 / 能力 / 系统，item 40px；上下文栏 280 + 主区；Dock 360px **默认收起**，打开后挤占主区。
- 聊天主区在 1600px、Dock 收起时约 1088px；打开 Dock 后约 728px。
- Dock 有 文件 / 工作区 / 浏览器 / 轨迹 / 终端 五个 Tab；收起时右侧显示浮层按钮。
- 顶栏把"专家 + 模式 + 会话标题 + 当前会话 + 分享 + Dock 开关"挤在一行。

### 1.2 与 Octop 的差距

| 项 | Octop | 当前原型 | 影响 |
|---|---|---|---|
| 聊天顶栏 | 无全局 Header；聊天自带 `ChatTitleBar`（标题 + 置顶/重命名/分支/删除），移动端另有一套工具栏 | 全局 topbar 兼做标题栏，信息密度高 | 1600 以下拥挤；标题/操作层级不清晰 |
| 会话列表 | 按专家分组；搜索；新建；每会话菜单（置顶/重命名/分支/删除）；加载更多 | 已加搜索/菜单/新建，切换会话会切消息、草稿、Dock 与滚动位置 | 置顶/分支仍是演示 |
| 消息区 | 历史分页（加载更早）、自动滚动、滚动到底按钮、Turn 时间线 | 无分页、无滚动到底、无新消息分隔 | 长会话不可用 |
| Dock | 可拖宽、可切上/下布局、文件/工作区/浏览器/终端/轨迹、Tab 保活 | 固定宽度、Tab 切换、无拖宽/布局切换 | 工作台感不足 |
| 浮层按钮 | 右侧竖排：资料/工作区/文件/终端/轨迹/浏览器（Dock 关闭时） | 已加 4 个（资料/工作区/轨迹/浏览器） | 少了文件/终端 |
| 响应式 | 桌面三栏；移动端抽屉 + 独立工具栏 | <1120 隐藏 Dock，<960 隐藏侧栏；聊天标题不收敛 | 中屏布局会挤 |

### 1.3 建议

- 顶栏拆成两层：**会话标题栏**（标题 + 状态 + 会话操作）与**工具行**（分享/Dock/更多），或把"专家 + 模式"移到标题栏左侧的紧凑块。
- 会话切换必须同时切消息、Dock、输入草稿；否则不要显示为可点。
- 消息区加：滚动到底按钮、加载更早、未读分隔线。
- Dock 支持拖宽（`resize`）与上/下布局切换；至少给一个"最大化"。
- 窄屏隐藏"当前会话"Tag 和分享按钮，只留标题 + more。

## 3. 按钮交互差距

### 3.1 已有改善

- 侧栏、用户菜单、配置页按钮都有文字；纯图标按钮有 `title`。
- 危险操作（停止任务、删除、退出）走确认弹窗。
- 主要流程有 toast。

### 3.2 仍缺

| 问题 | 例子 | 建议 |
|---|---|---|
| 大量 `toast-demo` | 附件、语音、导出、预览、探测 | 已清零：实现或明确禁用，不再灰色可点 |
| 无 loading | 保存/测试/探测/发送 | 按钮进入 loading + 禁用，防重复点击 |
| 无 disabled 解释 | 模型未配置、无权限、运行中 | 禁用 + tooltip 说明原因 |
| 确认级别不统一 | 删除会话/连接器/文档 | 统一 L3 Modal；L4 用于删除用户/恢复备份 |
| 图标按钮不可键盘聚焦 | 会话 more、Dock 关闭 | 用 `<button>` + `aria-label` + focus ring |
| hover-only 操作 | 消息复制/重生成 | 移动端/键盘也要可见（focus-within） |
| 位置不一致 | 任务卡"删除/停止"在左，详情在右 | 危险操作统一右侧/末位 |
| 空态按钮缺失 | 无会话、无文档、无连接 | 每个空态给一个主操作 |

### 3.3 按钮分级建议

| 级别 | 场景 | 交互 |
|---|---|---|
| L1 | 切换/展开/复制/发送 | 立即执行，可 toast |
| L2 | 保存/启用/测试 | loading + 成功/失败 toast |
| L3 | 删除会话/连接器/文档、停止任务 | Modal 确认 |
| L4 | 删除用户、关闭 MFA、恢复备份 | 输入名称/密码 |
