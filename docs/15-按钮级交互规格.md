# 15 · 按钮级交互规格

> 目的：把"页面长什么样"推进到"每个按钮什么时候可点、点了发生什么、失败怎么显示"。
> 覆盖 11 个高频界面、约 95 个按钮。每个按钮给：**可用条件 / 接口 / 确认级别 / 成功失败 / 快捷键 / 埋点**。
> 约定：`P?` = 权限点；`L1–L4` = 确认级别（见 §2）；所有文案走 i18n key。
>
> 范围说明：本文覆盖最初 11 个高频界面。专家抽屉、连接器、知识库的逐按钮/逐字段规格见 [`23`](23-专家编辑抽屉规格.md)、[`24`](24-连接器与知识库交互规格.md)；现状差距与优先级见 [`25`](25-原型交互差距审计.md)。**当前唯一权威总表见 [`30`](30-按钮与页面状态总表.md)**。

## 1. 通用规则

### 1.1 按钮状态机

```
idle ──click──► loading ──ok──► success(自动回落)
                   └──error──► error(可重试) ──retry──► loading
disabled：条件不满足 / 无权限 / 对方状态变化
```

- `loading` 时按钮禁用 + spinner，宽度不变（防跳动）。
- 同一按钮 300ms 内重复点击忽略（防双击）。
- 乐观更新仅用于"可逆且低风险"：停止/回答/派工先本地置 `pending`，失败回滚 + toast。
- 不可逆操作（删除、恢复备份）必须等服务端确认后再移除 UI。

### 1.2 确认级别

| 级别 | 场景 | 交互 |
|---|---|---|
| **L1** | 可撤销、低风险 | 直接执行 + toast（可撤销） |
| **L2** | 有副作用、可恢复 | 轻确认（Popconfirm） |
| **L3** | 不可恢复 | 对话框 + 说明后果 + 主按钮危险色 |
| **L4** | 影响面大/批量 | 对话框 + 输入资源名/数量确认 + 影响清单 |

### 1.3 权限点

| 动作 | 权限 |
|---|---|
| 查看任务 | `task:read` |
| 停止/派工/追加预算 | `task:write` |
| 回答待决 | `task:write` |
| 创建/编辑专家 | `agent:write` |
| 发布/回滚 | `agent:publish` |
| 知识库写 | `kb:write` |
| 插件安装/启停 | `extension:admin` |
| 来源配置 | `source:write` |
| 管理台 | `admin:*` |

无权限：按钮不渲染（而非置灰），除非"置灰 + tooltip 说明缺哪个权限"更有引导价值（如升级入口）。

### 1.4 埋点

统一 `ui.button.click`，属性：`button_id, module, object_id, state_before, result, duration_ms, error_code`。
下文每行末尾的 `evt=` 是 `button_id`。

## 13. 实现与验收

### 13.1 前端实现约定

```ts
type ButtonSpec = {
  id: string;
  labelKey: string;
  icon?: string;
  permission?: string;
  enabledWhen: (ctx: Ctx) => boolean;
  confirm?: "L1" | "L2" | "L3" | "L4";
  run: (ctx: Ctx) => Promise<void>;
  optimistic?: "patch" | "remove" | "none";
  errorMap?: Record<string, string>; // code -> i18n key
};
```

- 所有按钮通过 `<ActionButton spec={...}>` 渲染，统一 loading/禁用/确认/埋点。
- 错误码 → 文案用 `utils/apiError`（与 `contracts` 的 `ErrorEnvelope` 对齐）。
- 破坏性按钮（L3/L4）必须有 `aria-describedby` 指向后果说明。

### 13.2 验收清单

- [ ] 95 个按钮均有 `enabledWhen` 与权限点，越权用例覆盖。
- [ ] L3/L4 按钮 100% 有确认与后果说明。
- [ ] 双击 300ms 内不重复发请求。
- [ ] 失败时输入/草稿不丢。
- [ ] 乐观更新失败可回滚（停止/回答/派工）。
- [ ] 每个按钮有埋点，可在看板看到点击→成功转化。
- [ ] 键盘可达（Tab/Enter/Esc），图标按钮有 `aria-label`。
- [ ] 中英文案无截断（375px 宽度）。
