# 12 · 任务中心与收件箱：组件级规格

> 目标：前端拿到这份文档就能直接写组件，不需要再猜"这个卡片有哪些状态、空的时候显示什么、移动端怎么放"。
> 上游：`04` §2.2/§5.14–5.17 定义了信息架构；本文把它拆到 **props / 状态 / 文案 / 响应式 / 可访问性 / 测试**。
> 约定：展示型组件**不发请求**（由容器注入数据）；所有组件接受 `className` 与 `data-testid`；文案一律走 i18n key。

---

## 1. 页面结构与路由

```
/tasks                 主从布局：筛选 + 列表 + 详情（桌面）；列表/详情二选一（移动）
/tasks?bucket=running  桶由 URL 决定（可分享、可刷新）
/tasks/:ticketId       详情；桌面右侧面板，移动整页
/tasks/sources         来源管理（Tab）
```

| 断点 | 布局 |
|---|---|
| ≥1280 | 三栏：筛选 240px ｜ 列表 380–480px（可拖拽）｜ 详情 flex |
| 768–1279 | 两栏：列表 360px ｜ 详情 flex；筛选收进抽屉 |
| <768 | 单栏：列表页 ↔ 详情页；收件箱为底部 Sheet；筛选为底部 Sheet |

**URL 参数**：`bucket`（attention/running/queued/done）、`source`、`executor`、`q`、`sort`、`attention`（高亮某条）。

## 2. 视图模型（VM）

容器层把 API 数据映射成 VM，展示组件只认 VM。

```ts
type Bucket = "attention" | "running" | "queued" | "done";
type TicketState = "open" | "ended";
type AssignmentState = "pending" | "running" | "ended" | "dead";
type AttentionKind = "approval" | "question" | "blocked";
type AttentionStatus = "pending" | "answered" | "expired" | "dismissed";
type ExecutorKind = "builtin" | "codex" | "claude_code" | "dsh";
type SourceKind = "github" | "feishu" | "wecom" | "dingtalk" | "email" | "webhook" | "schedule";

interface SourceVM {
  id: string;
  kind: SourceKind;
  name: string;
  status: "active" | "paused" | "degraded";
  lastEventAt?: string;
}

interface AttentionVM {
  id: string;
  kind: AttentionKind;
  question: string;
  options?: string[];
  status: AttentionStatus;
  expiresAt: string;
  ticketId: string;
  ticketTitle: string;
  source: SourceVM;
  actor?: { id: string; name: string };
}

interface AssignmentVM {
  id: string;
  executor: ExecutorKind;
  state: AssignmentState;
  progress?: number;        // 0–1，单调不减
  lastHeartbeatAt?: string;
  startedAt?: string;
  stalled?: boolean;        // watchdog 判定
  costMicros?: number;
  budgetMicros?: number;
}

interface TicketVM {
  id: string;
  title: string;
  bucket: Bucket;
  state: TicketState;
  source: SourceVM;
  actor: { id: string; name: string };
  createdAt: string;
  updatedAt: string;
  strength: "explicit" | "inferred";
  policyVersion: number;
  executor?: ExecutorKind;
  assignment?: AssignmentVM;
  attention?: AttentionVM;          // bucket=attention 时必填
  summary?: string;                 // 最近一条 report
  progress?: number;
  costMicros?: number;
  badges: BadgeVM[];                // 见 §4.3
}

interface BadgeVM {
  kind: "strength" | "executor" | "policy" | "stalled" | "budget" | "merged";
  label: string;
  tone: "neutral" | "info" | "warn" | "danger" | "success";
}
```

**桶归属规则**（服务端算好，前端不推导）：

| 桶 | 条件 |
|---|---|
| `attention` | 存在 `pending` 的 attention |
| `running` | 存在 `running` 的 assignment |
| `queued` | ticket open，且无 running assignment、无 pending attention |
| `done` | ticket ended |

## 3. 组件树

```

├─ TaskCenterHeader               # 标题、刷新、收件箱入口、视图切换
```

| prop | 类型 | 必填 | 默认 | 说明 |
|---|---|:--:|---|---|

### 4.4 `TaskProgress`

| prop | 类型 | 必填 | 默认 | 说明 |
|---|---|:--:|---|---|
| `progress` | `number` | ○ | — | 0–1；无则显示"阶段" |
| `stage` | `string` | ○ | — | 如"已读 12 文件 · 待跑测试" |
| `state` | `"running"\|"stalled"\|"waiting"\|"done"\|"failed"` | ● | — | 决定颜色与动画 |
| `showPercent` | `boolean` | ○ | `false` | |

- `running`：条纹动画；`stalled`：黄色 + 不滚动；`waiting`：虚线；`done`：绿色满格；`failed`：红色。
- 无障碍：`role="progressbar" aria-valuemin=0 aria-valuemax=100 aria-valuenow=Math.round(p*100)`；无 `progress` 时退化为文本，`role="status"`。

### 4.5 `AttentionCountdown`

| prop | 类型 | 必填 | 默认 | 说明 |
|---|---|:--:|---|---|
| `expiresAt` | `string` | ● | — | ISO |
| `onExpire` | `() => void` | ○ | — | |
| `compact` | `boolean` | ○ | `false` | 只显示 mm:ss |

- 剩余 >1h 显示"剩 3 小时"；<1h 显示"剩 42 分钟"；<5min 变红并每秒刷新。
- 组件内部 1s tick，但**只在可见时**（`IntersectionObserver`）避免整页重渲染。

**结构**

```
┌──────────────────────────────────────────────────────────┐
│ [src] #412 修复登录超时          [inferred][claude-code] │
│ @alice · 12 分钟前 · 策略 v7                             │
│ ▓▓▓▓▓▓░░░░  读 12 文件 · 改 3 文件 · 待跑测试            │
│ ⚠ 需要你决定：是否允许修改 CI 配置？      [允许][拒绝]     │
└──────────────────────────────────────────────────────────┘
```

**状态矩阵**

| 状态 | 左侧条 | 进度 | 操作 |
|---|---|---|---|
| attention | 红色 | 隐藏 | 允许/拒绝/查看 |
| running | 蓝色（流动） | 显示 | 停止/查看 |
| queued | 灰色 | 隐藏 | 查看/取消排队 |
| done | 绿色 | 100% | 查看/再次执行 |
| stalled | 黄色 | 虚线 + 告警 | 停止/查看诊断 |
| failed | 红色 | 0 | 重试/查看 |

- 悬停：浅底 + 右侧出现 `⋯`（停止、复制链接、静音）。
- 选中：左侧 3px 主色 + 浅底。

### 7.2 `AttentionCard`

| prop | 类型 | 必填 | 默认 | 说明 |
|---|---|:--:|---|---|
| `attention` | `AttentionVM` | ● | — | |
| `onApprove` / `onDeny` / `onAnswer` | `(value?) => Promise<void>` | ○ | — | 按 kind |
| `onSnooze` | `(until) => void` | ○ | — | 10 分钟/1 小时/明天 |
| `onOpenTicket` | `() => void` | ● | — | |
| `busy` | `boolean` | ○ | `false` | 提交中，禁用按钮 |

**三类形态**

| kind | 主体 | 主按钮 | 次按钮 |
|---|---|---|---|
| `approval` | 工具名 + 人话摘要 + 参数预览 + 风险 | 允许 | 拒绝 / 本会话允许 |
| `question` | 问题 + 选项 + 自由输入 | 提交 | 转成对话 |
| `blocked` | 原因（预算/权限/依赖）+ 影响 | 追加预算 / 去授权 | 停止 |

- 风险 `high/critical` 时按钮为危险色，并要求二次确认。
- 提交中：按钮 spinner，卡片半透明，禁止重复点击。
- 失败：卡片内错误条 + "重试"，不回滚输入。

## 8. 空态、错误与提示文案

### 8.1 空态（`EmptyState` 变体）

| 场景 | 标题（zh） | 描述（zh） | 主操作 | 英文 key |
|---|---|---|---|---|
| 全部为空（首次） | 还没有任务 | Agent 只会在你允许的来源上接活。 | 接入来源 | `tasks.empty.first` |
| 待我决定为空 | 没有需要你决定的事 | Agent 会继续处理进行中的任务。 | 查看进行中 | `tasks.empty.attention` |
| 进行中为空 | 当前没有执行中的任务 | 已排队的任务会在执行器空闲后开始。 | 查看已排队 | `tasks.empty.running` |
| 已排队为空 | 队列是空的 | 新任务会自动出现在这里。 | — | `tasks.empty.queued` |
| 已完成为空 | 还没有完成的任务 | 完成的任务会保留在这里，可回看产物。 | — | `tasks.empty.done` |
| 筛选无结果 | 没有匹配的任务 | 试试清除筛选或换个关键词。 | 清除筛选 | `tasks.empty.filtered` |
| 未接入来源 | 尚未接入任何来源 | 接入 GitHub、飞书或 Webhook 后，Agent 才能接活。 | 接入 GitHub / 接入飞书 | `tasks.empty.sources` |
| 无权限 | 你还没有查看任务的权限 | 请联系管理员开通 `task:read`。 | 返回对话 | `tasks.empty.forbidden` |
| 加载失败 | 加载失败 | 网络或服务异常，请重试。 | 重试 / 查看诊断 | `tasks.empty.error` |
| 报告为空 | 执行器还没有提交报告 | 任务开始后这里会显示进度。 | — | `ticket.reports.empty` |
| 任务线为空 | 还没有事件 | 收到第一条事件后会显示在这里。 | — | `ticket.timeline.empty` |
| 产物为空 | 还没有产物 | 任务生成文件、PR 或报告后会显示。 | — | `ticket.artifacts.empty` |
| 收件箱为空 | 没有待你决定的事 | 有事时这里会亮起。 | — | `inbox.empty` |

### 8.2 错误与横幅

| 场景 | 文案 | 动作 |
|---|---|---|
| 断线 | 连接已断开，正在重试（3/10） | 查看诊断 |
| 数据可能过期 | 连接中断期间任务可能有更新 | 刷新 |
| 来源异常 | {source} 最近同步失败，任务可能延迟 | 去来源设置 |
| 执行器卡住 | 任务可能卡住了（{n} 分钟无心跳） | 查看诊断 / 停止 |
| 预算耗尽 | 已超出本任务预算 | 追加预算 / 停止 |
| 授权失效 | 授权已失效，需要重新确认 | 查看详情 |
| 批量部分失败 | {ok} 个成功，{fail} 个失败 | 查看失败项 |

### 8.3 Toast

| 动作 | 文案 |
|---|---|
| 停止 | 已停止。该线程不会再自动接单。 |
| 重新派工 | 已派给 {executor}。 |
| 追加预算 | 预算已更新为 {amount}。 |
| 回答 | 已提交，Agent 会继续。 |
| 合并 | 已合并到 #{id}。 |
| 复制链接 | 链接已复制。 |

## 9. 交互细节

| 交互 | 规格 |
|---|---|
| 选中 | 更新 URL `/tasks/:id`；桌面右栏渲染，移动推入新页 |
| 返回 | 浏览器返回回到列表并保留滚动位置 |
| 乐观更新 | 停止/回答/派工先本地置 `pending`，失败回滚 + toast |
| 实时 | 订阅 `user:{id}`（attention）与当前 `ticket:{id}`（assignment/report） |
| 去重 | 按 `(stream_id, seq)`；断线后 `after_seq` 补齐 |
| 批量 | 仅同类可批量；超过 20 条禁止 |
| 静音 | `snooze` 本地存储 + 服务端 `dismissed_until`；到点恢复 |
| 撤销 | 停止不可撤销（需重新开单）；回答可在 5s 内撤销 |
| 键盘 | `j/k` 移动、`Enter` 打开、`a` 允许、`d` 拒绝、`s` 停止、`/` 搜索、`⌘⇧A` 收件箱、`Esc` 关闭 |
| 加载更多 | 列表底部哨兵；详情时间轴向上分页 |
| 未读数 | 收件箱徽标 = pending attention 数；任务 Tab 红点 = 有 attention 的 ticket 数 |

## 12. 可访问性

- 列表 `role="list"`，卡片 `role="listitem" tabindex=0`，`aria-selected`。
- Tab `role="tablist"` + 方向键；`aria-controls` 指向面板。
- 进度 `role="progressbar"`；状态变化用 `aria-live="polite"`（不打断）。
- 危险按钮有 `aria-describedby` 指向后果说明。
- 收件箱 Drawer：焦点陷阱，`Esc` 关闭，关闭后焦点回到铃铛。
- 所有图标按钮有 `aria-label`；不用颜色单独表达状态（配图标/文字）。
- 对比度 ≥ 4.5:1；暗色主题下红色需单独校验。
