## 1. 左侧菜单栏：Octop 的实际结构

### 1.1 尺寸与状态

| 项 | Octop | 说明 |
|---|---|---|
| 展开宽 | `EXPANDED_WIDTH = 220` | 约 220px，图标 16px + 文案 |
| 折叠宽 | `COLLAPSED_WIDTH = 56` | 只留图标，hover 出 tooltip |
| 顶部 | Logo + 折叠按钮 | 折叠按钮在品牌行右侧 |
| 底部 | 用户头像 + 名称 + 角色 + 展开箭头 | 点击弹账户菜单，不是跳页 |
| 激活态 | 主色浅底 + 主色文字/图标 | 不用整块深色 |
| 角标 | 任务/收件箱数字 | 只给"需要处理"的入口 |

### 1.2 分组

Octop 是 **19 项、4 组**：

1. 顶部未分组：对话、专家、任务、Token 用量
2. 设置：个性化、通道、连接器、技能包、知识库、云端协同
3. 控制：工作台、远程桌面、ACP 协作
4. 管理：用户、模型、存储、插件、安全、应用设置

它的关键不是"19 个"，而是：

- **一级入口按对象分组**，不是按页面类型堆；
- **组标题是弱文字**，不抢主项；
- **底部只放账户**，设置/管理仍在一级组里；
- **没有二级侧栏**。设置、管理、连接器、知识库进入后是页面内 Tab、分段控件、卡片或抽屉，不会在 220px 旁边再长出一条 260px 的菜单。

### 1.3 我们此前的错误

原型曾经是：

```
232px 全局侧栏 + 280px 设置/管理侧栏 + 内容
```

（现已改为 220px 单层，折叠 56px；折叠后 logo 下方保留展开箭头，避免找不到入口；分组为 工作 / 能力 / 系统，item 40px、图标 17px、组标题 10.5px。）

这会产生"已经点过菜单，怎么又出现一层菜单"的断裂感，且 1280 下主内容只剩 700 多像素。现在已改为：

- 一级 **8 + 3**：对话、任务、专家、知识、连接、扩展、工作台、用量 + 设置、管理、头像；
- 设置/管理/连接/扩展/知识库/工作台/用量 **不再有第二层侧栏**；
- 二级切换改为页内 Tab；
- 只有对话的会话列表、任务的筛选面板保留第二栏，因为它们是"上下文面板"，不是导航。

## 2. 页面骨架与按钮层级

Octop 桌面端没有全局 Header。每个页面用 `PageShell`：

```
标题行（20/600） + 右侧 actions
副标题（13，弱色）
内容卡（24 padding，8 radius，只有内容区滚动）
```

按钮层级固定：

| 层级 | 位置 | 样式 | 规则 |
|---|---|---|---|
| 页面主操作 | 标题行最右 | 主色实心 | 一页最多一个 |
| 次操作 | 主操作左侧 | 描边/浅色 | 可与主操作并列 |
| 行内操作 | 卡片/表格行右 | 文字按钮 | 危险操作放最右，红色 |
| 图标操作 | 卡片右上/工具栏 | 28–32px 方形 | 必须有 title/aria-label |
| 更多 | 行尾 `⋯` | 图标 | 低频/危险操作收进菜单 |
| 开关 | 设置行右 | Switch | 立即生效，失败回滚 |
| 分段 | 标题下/卡片头 | Segmented/Chip | 视图切换，不触发页面跳转 |

### 2.1 反馈约定

- 保存：按钮 loading + 禁用，成功 toast，失败保留表单并显示错误；
- 删除：确认弹窗，危险按钮在右；
- OAuth：抽屉显示授权状态，点击重新授权弹窗/新窗口，轮询后成功；
- 空态：一句解释 + 一个主操作，不堆图标；
- 异步加载：骨架/Spin，不用空白页；
- 不可用：置灰 + title 说明，不用"点了再 toast 演示"。

## 3. 逐页复核

### 3.1 设置

Octop 是 `PageShell` + 页内 Tabs：外观、通知、快捷键、账号。

- 资料卡在标题下，不占侧栏；
- 设置项一行一个：左标签+说明，右控件；
- 主题/配色/密度用 Chip 或色块；
- 保存是行内小按钮，不是整页底部大按钮。

原型已对齐：页内 4 Tab，去掉第二层侧栏。

### 3.2 管理

Octop 的管理页是独立一级入口，进入后用页面内 Tabs/面板，不再套侧栏。

原型：概览 + 用户/模型/存储/插件/安全/应用设置 7 个页内 Tab；子页里再分用户/角色/分组、环境变量/备份/HTTPS/更新/通行密钥。层级是"一级侧栏 → 页面 Tab → 内容"，不再出现第三层菜单。

### 3.3 Token 用量

Octop：Segmented（概览/按天/按专家/按模型）+ 日期范围 + 导出 + 图表/表格。

原型已对齐：

- 4 个视图；
- 7/30/90 天；
- 柱状图有 Y 轴、日期、峰值/均值；
- CSV 导出；
- 明细表格。

### 3.4 连接器

Octop：

- 已启用 / 内置 / 自定义 MCP 三个 Tab；
- 实例卡：图标、名称、状态、工具数、默认打开、共享范围；
- 点卡片开配置抽屉；
- OAuth 类实例有授权状态与"重新授权"；
- 自定义 MCP 支持 JSON/可视化、探测、一键 OAuth。

原型已补：

- 实例抽屉：名称/描述/凭证/认证方式/默认选中/共享范围；
- 授权状态卡；
- 重新授权三步弹窗（打开授权页 → 等待 → 成功）；
- 测试连接；保存空名称拦截；`fail` 名称模拟服务端失败且不落库。

### 3.5 扩展 / 插件 / 技能包

Octop 插件页有已安装、市场、分组、权限标签、启用开关；技能包页有已安装/内置/市场。

原型已补：

- 插件：已安装/市场、安装、更新、卸载、启停；
- 技能包：已安装/内置/市场、安装、更新、启停；
- 市场卡先展示权限，再安装。

### 3.6 知识库

Octop：知识库列表 → 文档树/表格 → 预览/编辑 → 检索测试/设置。

原型已补：

- KB 切换 chips，不再用第二层侧栏；
- 文档/检索/设置 页内 Tab；
- 文档搜索（实时）；
- 全选/单选、批量重建/删除；
- 预览弹窗 + "定位到列表"联动。

### 3.7 管理端表单

原型已补：

- 邀请成员：邮箱格式校验，错误留在弹窗内；
- 环境变量：KEY 大写/数字/下划线、重复校验、空值校验；
- 保存失败（值含 `fail`）回滚到上次配置并提示；
- 保存按钮 loading + 防重复。
