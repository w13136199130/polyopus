# 52 · 模块布局与交互对齐规范（v7）

> 参照本地 Octop `1.0.3b7` 的**布局、功能组织与交互方式**，对 PolyOpus 原型的五个模块（对话 / 专家 / 自动化 / Token 统计 / 个性化）做结构调整。
>
> **配色不跟随 Octop**：品牌色仍是 PolyOpus 自己的 `#1677FF`（tech），中性色、圆角、阴影沿用一套中性设计令牌；只有"结构、节奏、交互"参考 Octop。可交互版本见 [`prototype/`](../prototype/)，截图见 `prototype/shots/`。

---

## 1. 原则

| 借 | 不借 |
|---|---|
| 页面骨架（页头 + 页内 Tab + 过滤器 + 内容） | Octop 的 rose 品牌色（`#E85D75`） |
| 信息分组方式（"我的/团队/市场"、"已安装/内置/市场/技能包"） | Octop 的业务模型（专家的托管/云端、技能包、连接器等） |
| 组件形态（专家卡、技能卡、任务行、KPI 条、环形图） | Octop 的具体文案与数据 |
| 交互（分段切换、卡片/表格视图、右侧抽屉表单、空态引导） | 它与 PolyOpus 冲突的导航层级 |

一句话：**结构照抄，皮肤保留**。

## 4. 专家

从"KPI + 卡片 + 右侧面板"改成 Octop 的三段式：

1. **页内 Tab**：我的专家 / 我的团队 / 发现专家
2. **过滤器行**：`共 N 个专家` + 全部/本地/云端/共享（文字分段）+ 搜索 + 卡片/表格切换 + 刷新 + 添加云端专家 + 新建托管专家（BETA）+ 新建专家 + 从专家市场新建
3. **内容**：专家卡网格（4 列自适应）或表格

专家卡结构（对齐 Octop）：`头像 + 名称 + ID` / 右上开关 / 状态·模型·版本标签 / 两行描述 / 动作条（工作区、试运行、编辑、复制、更多 + 对话）。

发现专家：分类 chips（精选/全部/内容创作/技术/金融/教育/医疗健康/设计）+ 市场卡网格（名称、描述、技能数、创建）。

编辑抽屉保留既有的 9 分区结构（基本信息/模型与运行/配置文件/技能/子智能体/工作区/心跳/人格/版本），入口改为卡片上的编辑按钮。
