  （含 `eval.decided`）、Report、`costMicros`；

`accept`（confidence 0.93）；回调接收器在进程内启动；每次重建

## 5. 实施中抓到的真问题（已修）

1. **ticket turn 没有 `turns.ticket_id`**：V05-12 的 mandate scope gate
   对真实自动执行 turn 实际是失灵的。V05-16 在 `conversations.post_turn`
   按 execution_thread 回填（ADR-012），相关 e2e 补 `fs:write` scope。
2. **过期审批按 approve 恢复**：单条 answer 忽略 `resolve()` 返回的
   `denied`；V05-16 改为使用实际决策，并加自动过期 sweep。
3. **异步结果事件命名**：卡面写 `tool.result`，仓库契约已有
   `tool.async_started/completed/cancelled` + `tool.failed`；V05-17 按契约
   落事件并在 docs/03 注明映射。
4. **`test_two_workers_never_double_run_a_turn` 竞态**：队列 2/2 拆分时
   两个 worker 都停在 `stop.wait()`，测试先 join 再 stop 会卡 120s；
   V05-20 改为等 4 个 run 完成后再 stop/join。
5. **audit 的 filtered 行没有 ticket**：filtered trigger 本身不开票；
   ticket 查询会解析其 `trigger_id` 找到 gate/assessment 行，未开票的
   filtered 行按 trigger/actor 查（docs/48 V05-19 已写明）。
