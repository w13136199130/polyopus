## 3. v1.0 演示

`uv run python scripts/demo_v10.py`（exit 0）：

1. 租户隔离：A 管理员读 B 租户 ticket → 404
2. RBAC：member 读 `/admin/audit` → 403
3. 专家：创建 → 发布 v1 → 线程 pin `agentVersionId`
4. 知识：建库 → 上传 Markdown → 检索命中 `ops.md`
5. 配额：user 请求上限 1 → 第一条 202、第二条 402 `QUOTA_EXCEEDED`
6. 备份：创建 → status `ready` + checksum
7. Watchdog：注入 heartbeat 400s → `watchdog.alert` requeue
8. 停止：`POST /tickets/{id}/stop` → `ended`

证据：`data/demo-v10/evidence.json`（运行生成）。

## 5. 已知边界（不阻塞 v1.0）

- 插件只注册 manifest/工具白名单并热切换；插件工具的实际进程隔离执行留 v1.5。
- IM 推送留 v1.1；站内通知为真相。
- 设置页的系统项只读；运行时模型/存储切换需重启配置，不提供假开关。
- 知识库为 SQLite FTS5 词法检索，向量检索留后续批次。
