# v1.0 混沌与压测报告

> 证据：`uv run pytest tests/chaos -q`；`uv run python scripts/load_test.py`（退出码 0）。

## 混沌场景

| 场景 | 注入 | 断言 |
|---|---|---|
| 并发 turn | 20 个线程并发 `post_turn` 后逐个执行 | 20 个完成、每个 `turn.finished` 恰好 1 条（不丢不重） |
| DB 锁 | 一个连接持有 `BEGIN IMMEDIATE` 0.3s | 另一个连接等待后写入成功，不丢 turn |
| 时钟跳变 | `run_due(now)` 前进 301s → 回拨 10000s → 再前进 | 只触发 2 次；回拨不重复开票 |
| 磁盘满 | 备份 sha256 阶段抛 `OSError` | backup 行落 failed，业务表原样保留 |
