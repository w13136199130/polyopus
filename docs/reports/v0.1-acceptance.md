## 2. 方法

- **黑盒**：全部经 HTTP API 驱动（登录、线程、turn、SSE 事件、Attention 审批、webhook、工单、用量），
  不直接写库、不调内部函数。
- **可重复**：任务、断言、证据采集都在 [`scripts/burn_in.py`](../../scripts/burn_in.py)；
  一条命令重建 20 个任务，失败返回非零。
- **判据三层**：
  1. 事件链：`turn.queued → turn.started → message.* / tool.* / approval.* → usage.recorded → turn.finished`，
     且 seq 从 1 连续无洞；
  2. 行为：文件是否落盘/未落盘、错误码、HTTP 状态、CSV 表头、跨重启后的状态；
  3. 反作弊：每个 turn 必须使用真模型；路径穿越目标文件放在 workspace 外，检查内容不泄露。
- **「不崩」的定义**：单任务无超时（默认 300s）、无未捕获 5xx、进程存活、
  异常输入后 `/healthz` 仍 OK 且还能完成正常 turn。

## 6. 烧机抓出并修复的缺陷

### 6.1 DeepSeek thinking 模式：`reasoning_content` 未回传（阻塞审批恢复）

- **现象**：写入审批 approve 后，恢复轮最终模型调用返回 `HTTP 400`
  `The reasoning_content in the thinking mode must be passed back to the API`；
  文件已落盘，但 `approval.resolved`/`turn.resumed` 之后的 turn 卡住，前端永远等不到 `turn.finished`。
- **根因**：网关只解析 `delta.content`，丢弃了 `delta.reasoning_content`；恢复时重建的 assistant
  tool-call 消息没有该字段，思考模式直接拒绝。
- **修复**：
  - `kernel/models/gateway.py`：新增 `ReasoningDelta` 与 `ChatMessage.reasoning_content`；
  - `openai_compat.py`：解析并回传 `reasoning_content`；HTTP 错误信息带响应体（不再只有状态码）；
  - `workers/engine.py`：每轮收集 reasoning，工具轮次带回；审批暂停时把 reasoning 存进
    `approval.request_json`，**跨进程重启后恢复轮仍能回放**；
  - `attention/service.py`：`ApprovalRequest.reasoning` 持久化。
- **验证**：`tool-write-approve`、`restart-approval` 真模型通过；新增 2 个网关单测
  （reasoning delta 解析、回传 wire 字段）。

### 6.2 工单测试竞态 + 旧错误码

- **现象**：全量套件偶发 `test_assignment_runs_ticket_to_ready_report` 失败，
  `UNIQUE(turn_id, attempt)` → `THREAD_TURN_ACTIVE`。
- **根因**：该测试的 `TestClient` 默认带内嵌 worker，后台 worker 与显式 `run_assignment`
  抢同一个 turn；同时 `run_assignment` 捕获的还是旧码 `TURN_ACTIVE`。
- **修复**：fixture 显式 `embedded_worker=False`（测试声称由自己驱动 assignment）；
  `run_assignment` 改为捕获 `THREAD_TURN_ACTIVE`。
- **验证**：该文件单独通过，全量套件 142 passed。

## 8. 覆盖与局限（请按此理解结论）

- **任务集由开发者编写**，不是独立第三方评测集；20 个任务能证明「主路径不崩」，
  不能证明「任意任务都不崩」。这是 v0.1 出口判据的边界，不是 v1.0 的质量门槛。
- **单用户、单租户、单进程**：未覆盖多租户隔离、RBAC、配额、并发 worker 压测。
- **真实任务均在本机**：未接 GitHub/飞书等外部渠道，未跑 v0.5 的常驻 intake。
- **任务中心**只验证触发/列表/停止；assignment→Report 仍由测试内部驱动。
- **成本**未计价（无价表），token 数为网关上报值。
- 运行基线含本卡未提交改动；提交后建议用同一脚本重跑一次留档。
