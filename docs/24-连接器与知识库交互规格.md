# 24 · 连接器与知识库交互规格（逐按钮 / 逐状态）

> 对照源码：`dashboard/src/pages/Agent/Connectors/index.tsx`（95KB）、`CustomMcpTab.tsx`、`ConnectorConfigDrawer`、`dashboard/src/pages/KnowledgeBases/index.tsx`（143KB）、`TextDocumentEditorModal.tsx`。
> 说明：连接器和知识库是 Octop 里交互最重的两页。本文把"页面 → 抽屉 → 字段 → 状态 → 错误"拆到按钮级；检索测试是 PolyOpus 的增补，Octop 没有独立检索测试页。

# 第一部分：连接器

## 1. 页面骨架

Octop 实际是 **3 个 Tab**（不是 5 个）：

| Tab | 内容 | 空态 |
|---|---|---|
| 已启用连接器 | 已创建的连接器实例卡 | 「还没有已启用的连接器」+ 浏览内置 / 添加自定义 MCP |
| 内置连接器 | 服务目录（按分类分组） | 无（目录始终有） |
| 自定义连接器 | MCP 服务器（可视化 / JSON） | 「尚未添加自定义 MCP」 |

页头：

| 控件 | 行为 |
|---|---|
| 标题「连接器」+ 副标题 | `PageShell` |
| 添加自定义 MCP | 跳到自定义 Tab 并打开新建卡（或直接打开编辑器） |
| 搜索 | 按名称/分类过滤目录 |
| 分类筛选 | 办公协作 / 笔记与知识 / 出行与地图 / 通讯与效率 / 资讯与娱乐 / 专业工具 / 自托管 |

> Octop 的 `tabMine / tabCatalog` 文案仍存在 locale，但当前页面用 `enabled / builtin / custom` 三 Tab；PolyOpus 保持三 Tab，避免多一层概念。

## 2. 已启用连接器（实例卡）

每张卡：

| 区域 | 内容 |
|---|---|
| 头部 | 图标 + 显示名 + 类型徽标 + 状态（已连接/缺少凭证/已过期） |
| 描述 | 描述、账号/工作区、共享来源（来自 xx） |
| 元信息 | 默认打开、共享范围、工具数 |
| 操作 | 配置、测试连接、启用/停用、设为默认、删除 |

按钮规则：

| 按钮 | 条件 | 行为 | 级别 |
|---|---|---|---|
| 配置 | 自己是所有者 | 打开配置 Drawer | L1 |
| 测试连接 | 已配置 | 探测 + loading + 结果 toast | L2 |
| 启用/停用 | 自己是所有者 | 调接口；关闭后专家不再加载工具 | L2 |
| 默认打开 | 已启用 | 用户的 Dashboard/IM/Cron 默认带上 | L2 |
| 删除 | 自己是所有者 | 弹窗确认，提示会影响使用该实例的专家 | L3 |
| 共享 | 有权限 | 仅自己 / 所有人 / 指定分组 | L2 |

只读态：别人共享的实例显示「共享连接器，仅所有者可管理」，配置按钮禁用，测试可用。

## 3. 内置连接器目录

每个服务卡：

- 图标、名称、一句话描述、分类、认证方式徽标。
- 已配置显示「已连接」+ 实例数；未配置显示「点击连接」。
- 按钮：`添加连接` / `配置`（已存在实例）。

分类与典型服务（来自 `connectorDefs.tsx` + locale）：

| 分类 | 服务 |
|---|---|
| 办公协作 | 飞书、企业微信、钉钉、QQ、腾讯会议、腾讯文档 |
| 笔记与知识 | Notion、语雀、Obsidian、IMA、乐享 |
| 出行与地图 | 高德/腾讯地图等 |
| 通讯与效率 | 邮箱（QQ/网易/Gmail/自定义 IMAP）、Agent Mail |
| 资讯与娱乐 | 腾讯新闻、B 站等 |
| 专业工具 | 企查查、天气等 |
| 自托管 / 扩展 | 自定义 MCP、Dify MCP |

## 4. 连接器配置 Drawer（按认证方式）

通用字段：

| 字段 | 规则 |
|---|---|
| 显示名称 | 必填，实例内唯一 |
| 描述 | 可选 |
| 默认打开 | Switch；关闭后需在对话中手动勾选 |
| 共享范围 | 仅自己 / 所有人 / 指定分组；共享后别人只读 |
| 凭据 | 按 `auth_kind` 动态渲染 |
| 测试连接 | 保存前/后都可探测 |

按认证方式的字段：

| auth_kind | 字段 | 典型服务 |
|---|---|---|
| `personal_token` | Token（粘贴）/ 打开授权页 / 从剪贴板粘贴 | GitHub、Notion（部分） |
| `oauth2` | 一键授权 / access_token / refresh_token / expires_at / client_id / client_secret / openid | 飞书用户授权、Notion、Google |
| `auth_code` | 授权码 | 企业微信扫码等 |
| `api_key` | API Key / App ID / App Secret / Bot ID / Bot Secret / Client ID | 飞书应用、企微机器人、IMA |
| `cookie` | Cookie（高级模式） | 未开放 OAuth 的服务 |
| `mail` | 邮箱服务商、邮箱、授权码/密码、IMAP、SMTP | QQ/网易/Gmail/自定义 |

OAuth 状态机：

```
未授权 → 点击一键授权 → 弹窗/新窗口 → 授权中
      → 成功：已授权（显示过期时间） → 过期：重新授权
      → 失败：错误 toast + 保留未授权
      → 弹窗被拦截：提示允许弹窗
```

按钮：

| 按钮 | 行为 | 级别 |
|---|---|---|
| 一键授权 | 打开 OAuth 窗口；完成后自动探测 | L1 |
| 打开并登录 | 打开服务登录页 | L1 |
| 从剪贴板粘贴 | 读剪贴板，失败提示手动粘贴 | L1 |
| 显示/收起高级 | 展开 Cookie/手动 Token | L1 |
| 测试连接 | 探测工具列表；成功显示「发现 N 个工具」 | L2 |
| 保存 | 校验 → 创建/更新 → 关闭 | L2 |
| 删除 | 确认；若被专家引用，提示引用列表 | L3 |

## 5. 自定义 MCP

顶部：

| 控件 | 行为 |
|---|---|
| 可视化 / `</> JSON` | 两种编辑模式切换；切换时校验 JSON |
| 添加 HTTP Server | 新增 HTTP 卡 |
| 添加 Stdio Server | 新增 Stdio 卡 |
| 探测 | 对每个 server 发请求，显示工具数/错误 |
| 保存 | 校验 → 写配置 → 可选自动探测 |

HTTP 卡字段：

| 字段 | 说明 |
|---|---|
| 显示名称 | 对话中选择时显示 |
| Server ID | 字母/数字/下划线/连字符，唯一 |
| Transport | HTTP / Stdio |
| URL | HTTP 地址 |
| Headers | 每行 `Key: Value`，可 Bearer |
| 启用 | 关闭后专家不加载 |
| 默认打开 | 对话默认选中 |
| OAuth | 需要时一键授权 |

Stdio 卡字段：

| 字段 | 说明 |
|---|---|
| 显示名称 / Server ID | 同上 |
| Command | 启动命令 |
| Args | 一行一个参数 |
| Env | 每行 `KEY=VALUE` |
| 启用 / 默认打开 | 同上 |

JSON 模式：整段 JSON 编辑器，保存前校验；错误定位到行。

OAuth 提示：

- 探测返回 401/需要 OAuth：显示「此 MCP 需要 OAuth 授权」+ 一键授权。
- 未授权时启用按钮禁用，提示先授权。

删除：L3；已保存的立即删除，未保存的只从当前编辑移除。

# 第二部分：知识库

## 6. 页面骨架（Octop 实际）

单页，不是 Tab 页：

```
PageShell
├─ 左：知识库列表（可收起、可拖宽）
└─ 右：当前知识库
   ├─ 头部：图标/名称/ID/创建者/默认/共享 + 更多
   ├─ 工具栏：返回、路径面包屑、搜索、视图切换、上传、新建文件/文件夹、刷新
   ├─ 文件树（可收起、可拖宽）
   ├─ 文档表/卡片
   └─ 预览 Modal / 文档编辑 Modal
```

页头按钮：

| 按钮 | 行为 |
|---|---|
| 创建知识库 | 打开创建 Drawer |
| 知识库设置 | 打开实例级设置（启用、向量模型、OCR、上限） |
| 搜索 | 过滤文档 |
| 上传文档 | 打开上传/拖拽 |
| 新建文件 | 打开 `TextDocumentEditorModal` |
| 新建文件夹 | 弹窗输入名称 |
| 刷新 | 重新拉列表 |
| 视图切换 | 表格 / 卡片 |

## 7. 知识库创建 / 编辑 Drawer

| 字段 | 规则 |
|---|---|
| 名称 | 必填 |
| 描述 | 可选 |
| 图标 | 预设图标或上传头像 |
| 默认启用 | Switch；只对创建者生效 |
| 共享 | 仅自己 / 所有人 / 指定分组；共享后别人可读可选用，仅所有者可编辑 |
| 文档上限 | 0=不限制，默认 100 |

按钮：取消 / 保存（L2）；删除知识库（L3，二次确认「删除知识库及其所有文档」）。

## 8. 文档操作

| 按钮 | 行为 | 级别 |
|---|---|---|
| 上传 | 支持拖拽；多文件；显示进度/队列 | L1 |
| 新建文件 | 文件名 + 格式（md/txt）+ 内容 | L2 |
| 新建文件夹 | 名称 | L2 |
| 预览 | 文本/PDF/Office/图片预览；大纲、查找、上一页/下一页、全屏、下载 | L1 |
| 编辑 | 文本文件打开编辑器 | L1 |
| 重建索引 | Popconfirm「重新解析并嵌入此文档？」 | L3 |
| 重命名 | 文件夹/文档 | L2 |
| 删除 | 文档 L3；文件夹 L3（含内部文档） | L3 |
| 下载 | 原文件 | L1 |

状态：

| 状态 | 展示 |
|---|---|
| pending | 待处理 |
| processing | 处理中（进度/转圈） |
| ready | 已就绪（切片数） |
| failed | 失败（错误信息 tooltip，可重建） |

上传限制：单文件大小、文档数上限、支持格式（md/txt/rst/html/json/yaml、csv/tsv/xls/xlsx/xlsm、pdf/doc/wps/docx/pptx、图片 OCR）。超限时按钮禁用并显示具体上限。

## 9. 知识库设置（实例级）

| 分区 | 字段 |
|---|---|
| 启用知识库 | 总开关；关闭后全实例不可用 |
| 向量模型 | 本地 ONNX / 在线 Embedding；选择 provider + model；切换会重建全部索引（L3） |
| 本地模型 | 下载/删除/大小/进度；运行时组件/权重/实际编码检测 |
| OCR | 关闭 / 本地 ONNX / 在线视觉模型；图片与扫描 PDF |
| 限制 | 单文件大小、文档上限、每用户知识库上限 |
| 共享 | 默认启用只对创建者生效；共享后其他人可读 |

保存：L2；切换向量模型需 L3 确认并显示「会重建全部索引」。

## 10. 检索测试（PolyOpus 增补）

Octop 没有独立检索测试页；PolyOpus 增加：

| 控件 | 行为 |
|---|---|
| 问题输入 | 必填 |
| TopK | 1–20，默认 5 |
| 检索模式 | 向量 / 关键词 / 混合 |
| 检索 | 显示命中切片、来源文档、分数、耗时 |
| 引用 | 一键复制引用 / 插入对话 |
| 空态 | 「没有命中」+ 调整问题/降低阈值 |

结果字段：文档名、路径、切片序号、分数、文本、高亮 query。

## 11. 错误与空态

| 场景 | 文案/行为 |
|---|---|
| 知识库未启用 | 整页空态「知识库尚未就绪」+ 去设置 |
| 未配置向量模型 | 「请先配置向量模型」+ 管理模型 |
| 达到文档上限 | 上传按钮禁用 + 「已达到 N 个文档上限」 |
| 单文件过大 | 上传前提示「单个文档不能超过 X MB」 |
| 解析失败 | 行内失败 tag + 错误详情 + 重建 |
| 预览不支持 | 「该文件类型不支持预览」+ 下载 |
| 无文档 | 「暂无文档 — 拖拽文件到此处，或点击上传」 |

## 12. API 映射（PolyOpus）

| 操作 | 方法/路径 |
|---|---|
| 知识库列表/创建/更新/删除 | `GET/POST/PATCH/DELETE /api/v1/knowledge-bases` |
| 文档列表 | `GET /api/v1/knowledge-bases/{id}/documents` |
| 上传 | `POST .../documents`（multipart） |
| 重建 | `POST .../documents/{docId}/reindex` |
| 删除 | `DELETE .../documents/{docId}` |
| 检索测试 | `POST .../query` |
| 设置 | `GET/PUT .../settings` |
| 连接器列表/实例 | `GET/POST/PATCH/DELETE /api/v1/connectors` |
| 探测 | `POST /api/v1/connectors/{id}/probe` |
| MCP 配置 | `GET/PUT /api/v1/connectors/mcp` |

## 13. 验收清单（DoD）

连接器：

- [ ] 三个 Tab 可切换；目录分类/搜索生效。
- [ ] 配置 Drawer 按认证方式渲染正确字段；保存/测试/删除可走通。
- [ ] OAuth 成功/失败/过期/弹窗被拦截四种状态都有提示。
- [ ] MCP 可视化/JSON 切换不丢数据；JSON 错误定位；探测显示工具数。
- [ ] 共享实例只读；默认打开只影响自己。
- [ ] 删除被引用实例有阻止/提示。

知识库：

- [ ] 创建/编辑/删除知识库；共享与默认启用语义正确。
- [ ] 上传队列、进度、失败重试、格式/大小限制。
- [ ] 文档树/搜索/视图切换/预览/编辑/重建/删除。
- [ ] 文档状态 pending/processing/ready/failed 可见。
- [ ] 向量模型切换有全量重建确认；OCR 设置可见。
- [ ] 检索测试返回切片/分数/来源；空态可操作。
- [ ] 达到上限、未启用、未配置模型三种空态有明确下一步。
