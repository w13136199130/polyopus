**固定夹具**：

| 夹具 | 内容 |
|---|---|
| `tenant_a` / `tenant_b` | 两个租户，各 1 管理员 + 2 用户 |

**级别**：Critical（越权/密钥泄漏/任意代码）、High（SSRF/注入成功/提权）、Medium（信息泄漏/DoS）、Low（配置缺失）。

## 13. Harness 与 CI

```python
# tests/security/conftest.py（示意）
@pytest.fixture
def canary_server():
    """本地 HTTP，记录所有请求；用于断言没有出站。"""
    ...

@pytest.fixture
def malicious_plugin():
    return build_plugin(read_ssh=True, outbound=True)
```

```bash
pytest tests/security -m "security and not slow"   # PR
pytest tests/security -m security                  # nightly
pytest tests/security --json-report --junitxml=...
```

| 触发 | 范围 | 失败策略 |
|---|---|---|
| PR | AUTH/AUTHZ/INJ/SSRF 基础 + WEB | Critical/High 阻断 |
| Nightly | 全量（含 DOS/PLUG/AGENT） | 生成报告 + issue |
| Release | 全量 + 手工渗透清单 | 阻断发布 |

## 14. 严重度与响应

| 级别 | 例子 | 响应 |
|---|---|---|
| Critical | 跨租户、任意代码、密钥泄漏 | 立即修，24h 内 hotfix |
| High | SSRF、注入成功、越权写 | 3 天内修 |
| Medium | 信息泄漏、DoS | 下个迭代 |
| Low | 配置缺失 | backlog |

**流程**：发现 → 复现（用例化）→ 修复 → 回归用例进 `tests/security` → postmortem（Critical）。
