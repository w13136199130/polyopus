# 23 · 专家编辑抽屉规格（逐字段 / 逐按钮）

> 对照源码：`dashboard/src/pages/Experts/components/EditAgentDrawer.tsx`（55KB）、`AgentBackendFields.tsx`、`AgentAdvancedConfigFields.tsx`、`WelcomeConfig.tsx`、`SkillCatalogDrawer.tsx`、`SubagentCatalogDrawer.tsx`。
> 结论先说：**Octop 不是 10 个 Tab，而是一个 520px 长抽屉 + 若干 Collapse 分区**；PolyOpus 为了降低滚动成本改用 Tab，但字段分组必须一一对应，不能借 Tab 之名漏字段。

---

## 1. 容器与骨架

| 项 | Octop 实现 | PolyOpus 采用 |
|---|---|---|
| 容器 | `Drawer width={520}`，右侧滑出 | 560px 右侧 Drawer（宽一点放模型/文件） |
| 标题 | `EditExpertDrawerTitle`：头像 + 名称 + 状态 | 头像 + 名称 + 状态 + 当前版本 |
| 底部 | 固定 `取消` / `保存` 两个按钮 | 固定 `取消` / `保存`；`发布`放页头 |
| 主体 | 长表单，分区标题；下方 Collapse：页面配置、配置文件、技能、子智能体、高级 | Tab：基本信息、模型与运行、配置文件、技能、子智能体、工作区、心跳与主动、人格与记忆、版本 |
| 关闭 | `destroyOnHidden` | 关闭时若有脏字段，弹 L3 确认 |

Tab 顺序（PolyOpus）：

1. 基本信息
2. 模型与运行
3. 配置文件（SOUL / IDENTITY / AGENTS / TOOLS / HEARTBEAT）
4. 技能
5. 子智能体
6. 工作区
7. 心跳与主动关心
8. 人格与记忆
9. 版本

## 2. 基本信息

| 字段 | 控件 | 默认/规则 | 说明 |
|---|---|---|---|
| 头像 | 头像选择器 + 上传 + 移除 | 可选 PNG/JPEG/WebP/GIF ≤5MB | 未设置时用配色图标；上传/删除即时生效（Octop 单独接口） |
| 配色 | 色板 + 自定义色 | 8 套预设 | 影响卡片与聊天气泡 |
| 名称 | Input | 必填，≤64 | 保存后列表/聊天同步 |
| 描述 | TextArea（2–5 行） | 可选，≤200 | 列表卡片与市场展示 |
| 欢迎语 | TextArea（2–5 行） | 可选 | 聊天欢迎页一行引导 |
| 可见范围 | 仅自己 / 所有人 / 指定分组 | 默认仅自己 | 选分组时出现分组多选；共享后别人只读 |
| 默认模式 | Ask / Plan / Act | 默认 Act | 新会话默认模式 |
| 默认模型 | Select（可搜索） | 默认「自动」 | 选项按已授权 provider 分组；空=系统默认 |
| 后端 | 本机 / Docker / 组合 | 默认本机 | 编辑时禁用（创建后不可改，Octop 明确 `disabled`） |
| 轨迹 | Switch | 默认开 | 写入运行轨迹，聊天页可见 |
| Composer 默认 | 模型/知识库/连接器默认值 | 可选 | 新会话的输入区默认选中 |

按钮：

| 按钮 | 行为 | 级别 |
|---|---|---|
| 更换头像 | 打开头像选择器 | L1 |
| 移除头像 | 删除已上传头像，回退配色图标 | L2 |
| 保存 | 校验 → PATCH → 关闭 | L2 |

校验失败定位到字段；保存中按钮 loading + 禁用；失败保留抽屉与输入。

## 3. 模型与运行

| 字段 | 控件 | 默认/规则 |
|---|---|---|
| Provider / 模型 | Select（分组、搜索） | 默认自动；只列已授权模型 |
| 最大迭代 | InputNumber | ≥1，默认 30 |
| 最大输入长度 | InputNumber | ≥1000，默认 128000 |
| Temperature | InputNumber | 0–2，默认 0.7 |
| Top P | InputNumber | 0–1，默认 1 |
| Max Tokens | InputNumber | 可选，留空由模型决定 |
| 记录轨迹 | Switch | 默认开 |
| 运行配置 | 高级折叠：请求会话 ID、请求用户 ID、超时 | 一般不改 |

禁用条件：

- 专家运行中：模型/后端可改但提示「新会话生效」；工作区根目录不可改。
- 远程专家（Bridge）：后端与根目录禁用，只读提示。
- 未授权任何 provider：模型选择禁用，显示「先到模型配置授权」。

## 4. 配置文件（SOUL / IDENTITY / AGENTS / TOOLS / HEARTBEAT）

Octop 的「配置文件」是一个 Collapse，列出工作区里的 Markdown 文件；点击行打开 `FileEditModal`，支持重命名/删除，右上角「打开工作区」。

| 行 | 内容 | 操作 |
|---|---|---|
| SOUL.md | 灵魂设定 | 点击编辑；更多：重命名 / 删除 |
| IDENTITY.md | 身份设定 | 同上 |
| USER.md | 用户档案 | 同上 |
| AGENTS.md | 行动指南 | 同上 |
| TOOLS.md | 工具说明 | 同上 |
| BOOTSTRAP.md | 启动引导 | 同上 |
| HEARTBEAT.md | 心跳任务 | 同上 |
| SKILL.md / skills/* | 技能说明 | 由技能区管理 |
| MEMORY.md | 记忆摘要 | 只读或编辑 |
| PROACTIVE.md | 主动推送 | 编辑 |

编辑器行为：

- 全屏 Modal / 侧滑编辑器，Monaco 或等宽 TextArea。
- 顶部文件名 + 保存状态（已保存/未保存）。
- `保存` 写文件；`取消` 若有改动弹确认。
- 文件不存在时给出「新建」入口。
- 保存后如专家运行中，提示「下次会话生效」。
- 重命名/删除为 L3；删除 SOUL 等核心文件要额外警告。

> 原型简化：用 TextArea 编辑 SOUL/AGENTS，保存写前端状态；不接文件系统。

## 5. 技能

> 运行时只注索引，正文按需读；详见 `02 §7.1.1` 与 `ADR-010`。本节管编辑态。

### 5.1 技能库

| 区域 | 内容 | 按钮 |
|---|---|---|
| 已安装技能 | 图标、名称、一句描述、来源（内置/工作区/技能包）、版本、启用开关 | 详情、删除、管理技能 |
| 搜索/筛选 | 按名称、来源、启用状态 | 清空 |
| 技能市场 | 搜索、分类、安装 | 安装（L2） |
| 空态 | 「还没有技能」+ 去市场 | 浏览技能市场 |

- 内置技能不可删除，只能停用；工作区技能删除 L3；被引用时阻止。
- 安装/卸载后刷新列表；运行中提示“下轮生效”。

### 5.2 技能详情（渐进披露）

| 字段 | 说明 |
|---|---|
| `name` / `description` / `when_to_use` | 必填；`when_to_use` 是索引里唯一会进 prompt 的补充 |
| `allowed-tools` | 与策略交集，取更严 |
| `version` / `dependencies` | 依赖缺失时禁止启用，并给出缺什么 |
| 正文 | 默认不加载；点“预览正文”才 `skill.read`，≤32KB，带 `content_hash` |
| 使用记录 | 最近使用轮次、命中原因（可选） |

### 5.3 技能包

| 区域 | 内容 | 按钮 |
|---|---|---|
| 文件树 | 目录/`SKILL.md`/脚本/资源；点击预览 | 新建、重命名、删除 |
| 元信息 | 名称、版本、依赖、头像、共享范围、复制策略 | 保存 |
| 共享 | `private/team/tenant` + 组 grant | 保存 |
| 导入/导出 | zip；校验路径穿越、文件数、总大小 | 导入、导出 |

### 5.4 运行时行为

1. system prompt 只放 `name + description + when_to_use`，正文不进前缀。
2. 每轮可传 `skills=[...]` allowlist；索引与执行都过滤。
3. 禁用双向生效：索引移除 + `skill.read` 返回 `SKILL_DISABLED`。
4. 消息上显示“本轮使用了哪些技能”，点击进详情；不显示正文。
5. 技能多时只增加索引行数，不按全文计入上下文。

## 7. 工作区

| 字段/按钮 | 行为 |
|---|---|
| 存储后端 | 选择已配置后端（本地/COS/S3/PostgreSQL/Docker）；编辑时只读 |
| 根目录 | 本机路径；保存前探测可写（Octop `probeRootDir`） |
| 打开工作区 | 打开 `WorkspaceDrawer`（文件树/预览/上传/下载/重命名/删除/新建） |
| 导入压缩包 | 合并 / 替换（L3） |
| 导出压缩包 | 下载 zip |
| 路径映射 | 组合后端时添加 路径 → 后端 映射；校验重复/空值 |

错误处理：

- 根目录不可写：阻止保存并给出修复建议。
- Docker 未安装：提示安装 Docker Desktop / 一键安装脚本。
- bubblewrap 缺失：保存后 toast 警告，不阻断。

## 10. 版本

| 列 | 内容 |
|---|---|
| 版本 | v3 / v2 / v1 |
| 状态 | 当前 / 已发布 / 初始 |
| 时间 | 发布时间 |
| 操作 | 回滚（L3）、查看差异 |

发布语义：

- `保存` 只保存草稿，不改变已发布版本。
- `发布` 生成新版本；新会话用新版本，进行中的会话锁定旧版本。
- `回滚` 只影响新会话；需确认。
