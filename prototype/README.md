# PolyOpus 可交互原型 v3（Octop 外壳对齐）

> 不是静态排版，也不是"只有图标"的侧栏。外壳对齐 Octop：**220px 展开侧栏（图标 + 文字）、56px 折叠、账户菜单、个人设置、管理端配置页**；导航按 [`04`](../docs/04-界面交互.md) 定稿为 **8 + 3**。配置页只保留一层侧栏，二级切换用页内 Tab。

## 打开

```bash
start prototype/index.html
# 或
python -m http.server 8788 --directory prototype
```

零依赖，`file://` 直接打开。主题、强调色、侧栏折叠状态存 `localStorage`。

## 真正可点的交互

- **对话**：Enter 发送、逐字流式、停止、队列、模式/模型/知识库菜单、`@`/`/` 插入、审批三选项、工具卡展开、复制/重新生成/分支。
- **消息编辑**：用户消息行内编辑，保存后截断该消息之后的内容并重新发送。
- **Ask 卡**：分步提问、选项/其他补充、跳过、审核提交（切到 s3）。
- **Plan 卡**：计划就绪、执行/继续编辑（切到 s4）；Plan 模式新回复会生成计划卡。
- **技能/子智能体**：输入区多选 chips，可单独移除。
- **@ 搜索**：文件/表格/知识库/专家/子智能体，Enter 插入。
- **/ 命令**：输入框按 `/` 或点按钮，搜索 `/new`、`/clear`、`/compact`、`/plan`、`/export` 等并执行。
- **快捷键**：`⌘K` 命令、`⌘N` 新对话、`⌘⇧A` 收件箱、`⌘.` 停止、`?` 快捷键表；设置 → 快捷键可自定义并持久化。
- **空态/错误**：`?state=error|nomodel|offline|noconn|adminempty` 可演示加载失败/无模型/离线/无连接器/管理空态。
- **连接器**：实例抽屉 + 授权状态 + 重新授权三步弹窗（打开授权页/等待/成功）。
- **扩展**：插件已安装/市场、安装/更新/卸载；技能包已安装/内置/市场、安装/更新/启停。
- **知识库**：实时搜索、全选/单选、批量重建/删除、预览后定位。
- **管理端**：邀请邮箱校验、环境变量 KEY/重复/空值校验、失败回滚。
- **P0 表单**：显示名称持久化；通知开关落 state；用户新建/邀请/启停/删除；提供商/存储配置校验并回写卡片状态。
- **P0 表格**：搜索、排序、分页、每页条数、行选择、批量操作、列显示；已套到用户/模型/插件/技能/审计。
- **P0 收尾**：`toast-demo` 清零；表单/邀请 dirty guard；上下文压缩、备份、远程桌面、云端协同、子智能体、人格/记忆等改为真实动作或明确禁用。
- **权限/错误**：账户菜单切换管理员/成员/只读审计；`?role=member`、`?role=auditor`；`?error=401` 登录页、`?error=403|409|500` 错误页、`?state=listfail` 列表失败；表单填 `conflict` 演示 409，填 `fail` 演示保存失败重试。
- **任务**：四桶切换、搜索、来源筛选、任务选中、允许/拒绝/回答/追加预算、停止二次确认、重新派工、新建任务。
- **收件箱**：全部/审批/提问/受阻筛选、回答弹窗、稍后、全部已读。
- **自动化**：创建定时任务表单、立即执行、删除确认。
- **专家**：卡片打开 9 分区编辑抽屉；字段可编辑；配置文件/技能/子智能体/工作区/心跳/人格/版本可切换；保存/发布/回滚。
- **连接器**：三 Tab 切换；实例卡配置抽屉（显示名、凭证、默认打开、共享）；测试连接、删除确认；MCP 可视化/JSON 切换、添加 Server、探测。
- **知识库**：文档树 + 表格、上传队列、搜索/视图切换、新建文件/文件夹、预览/重建/删除、检索测试、向量模型与 OCR 设置。
- **配置页**：模型提供商配置弹窗、用户新建/删除确认、存储配置、通道配置、安全开关、应用设置表单。
- **账户**：明暗/跟随系统、9 套配色、自定义颜色、布局、语言、SSO 绑定/解绑、退出确认。
- **全局**：`⌘K` 命令面板、toast、侧栏折叠持久化。

## 与 Octop 的关系

- 外壳尺寸、用户菜单、页面骨架、配置页组织方式对齐 Octop；配色名称与预设对齐它的 `header.palette.*`。
- 导航按 `04` 定稿为 **8+3**：Octop 的 19 项子页通过连接/扩展/工作台/管理 Hub 进入（连接→通道/云端协同/ACP；扩展→技能包/插件；工作台→远程桌面；管理→六个管理页）。
- 业务模型仍是 PolyOpus 的：Intake/Ticket/Attention/Mandate 是 Octop 没有的，所以"任务/收件箱"与"自动化（Cron）"分成两个入口。
- 详细逐按钮分析见 [`docs/22-Octop交互逐按钮分析.md`](../docs/22-Octop交互逐按钮分析.md)；专家/连接器/知识库规格见 [`23`](../docs/23-专家编辑抽屉规格.md)、[`24`](../docs/24-连接器与知识库交互规格.md)；现状差距见 [`25-原型交互差距审计.md`](../docs/25-原型交互差距审计.md)。

## 边界

数据写死；流式是前端定时器；附件/语音/OAuth/连接器测试/导出为演示入口；无后端。原型用于确认信息架构与按钮行为，不是像素级视觉稿。
