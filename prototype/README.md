# PolyOpus 可交互原型 v7（模块布局对齐版）

> 不是静态排版，也不是"只有图标"的侧栏。外壳对齐 Octop：**220px 展开侧栏（图标 + 文字）、56px 折叠、账户菜单、个人设置、管理端配置页**；导航按 [`04`](../docs/04-界面交互.md) 与 [`52`](../docs/52-模块布局与交互对齐规范.md) 为 **四组 21 项**（个人设置从账户菜单进入）。
>
> v7 参考 Octop 的**布局与交互**重构了五个模块（对话 / 专家 / 自动化 / Token 统计 / 个性化），配色仍用 PolyOpus 自己的品牌蓝 `#1677FF`。逐项依据见 [`52-模块布局与交互对齐规范`](../docs/52-模块布局与交互对齐规范.md)。
>
> v4 的重点不是加页面，而是把 v3 里"点得动但不会发生"的动作接成闭环：**假成功 → 真落库，死按钮 → 可完成，状态卡死 → 可恢复**。逐项评审依据见 [`51-原型界面评审与优化优先级`](../docs/51-原型界面评审与优化优先级.md)。

## 打开

```bash
start prototype/index.html          # 直接打开外壳
start prototype/matrix.html         # 原型矩阵（推荐从这里开始）
# 或
python -m http.server 8788 --directory prototype
```

零依赖，`file://` 直接打开。主题、强调色、侧栏折叠、显示名称、快捷键存 `localStorage`。

| 任务/收件箱 | 去掉顶部 KPI 与二级栏；筛选收进工具条（来源/执行器两排胶囊，收件箱用类型胶囊），右侧搜索 + 排序；收件箱是一级导航并带待决角标 |

| 知识库 | 去掉二级栏与 KPI：左侧库卡片（描述/创建者/文档数/默认开启 + 更多菜单），右侧面板「库名 + 卡片/表格 + 新建文件夹/新建文件/上传文档 + N/1000 文档 + 格式说明」，文档默认卡片网格；**知识库设置 / 编辑知识库都是右侧抽屉**，面板撑满视口高度 |

| 连接器 | 去掉 KPI/右侧栏/最近调用表；三个 Tab：已启用（卡片 + 虚线添加卡）、内置（分类 chips + 30 个紧凑卡）、自定义（JSON 示例 + 可视化/JSON + 虚线添加槽 + 已添加服务器） |

| 用户管理 | 8 个 Tab：用户/角色/分组 + 飞书·企微·钉钉·OIDC·LDAP 登录配置（左侧表单 + 右侧配置清单/登录预览/回调地址） |

| 模型配置 / 存储管理 | 模型配置 6 个 Tab（对话/向量/生成/语音/决策/搜索引擎）改为「模型池 + 提供商卡片」；存储管理 2 个 Tab（我的存储 / 支持存储类型 11 张卡）+ 配置抽屉 |
| 插件管理 / 安全防护 / 应用设置 | 插件管理拆成「已安装插件 / 插件市场 / 权限审计」，市场有分类 chips 与 27 个插件卡；安全防护与应用设置每个 Tab 顶部加说明条，保持「说明 + 设置卡」结构 |
| 管理组抽屉 | 提供商配置/自定义供应商 → 提供商抽屉（类型/Base URL/API Key/模型行/测试/保存）；插件安装与 ZIP 导入 → 安装抽屉（权限 chips）；存储后端 → 存储抽屉 |
| 对话 | 会话栏：搜索 → 专家/团队/云端 分段 → 创建专家 → 当前专家卡 → 会话列表；消息区：`N 步执行过程` 折叠（展开先看思考正文再看步骤）、助手淡墨气泡、消息工具栏、24 圆角输入框 + 用量条 |
| 专家 | 我的专家 / 我的团队 / 发现专家；过滤器行（共 N 个 + 全部/本地/云端/共享 + 搜索 + 卡片/表格 + 新建组）；专家卡（头像 + 名称 + ID、状态/模型/版本标签、动作条、对话）；市场分类 chips + 市场卡 |
| 自动化 | 专家 chip + 全部/已启用/已暂停；任务行（名称 + 类型/状态 + cron + 下次 + 开关 + 立即执行）；空态 3 条示例可点；右侧抽屉三段式表单（基础信息 / 执行计划 / 任务内容） |
| Token 统计 | 提示条 + 汇总/按天/按专家/按模型 + 过滤器 + **一行 7 段 KPI** + **4 张环形图** + 每日消耗趋势 + 明细表 |
| 个性化 | 页头右上角模块按钮（技能/子智能体/工具/插件/MBTI/记忆/通道）+ 专家 chip；技能 4 个子 Tab + 卡片网格；工具按能力分组开关；MBTI 四维条；记忆 KPI + 流水线 |

## 四条闭环主线（评审按这个点）

| 主线 | 路径 | 要点 |
|---|---|---|
| 发起 → 审批 → 执行 → 归档 | `?demo=ticket#/chat` → 开始任务 → 允许 → 完成 → 打开完整工单 | 对话内任务卡 → 真实 Ticket → 批准触发执行进度 → 完成写产物；每一步写任务线与审计 |
| 收件箱决策 | `#/inbox` | 已读与决策分离；批量批准/拒绝需确认；提问可**行内回答**（不弹窗）；失败项可重试 |
| 上传 → 解析 → 检索 → 重建 → 删除 | `#/knowledge` | 上传读取真实文件名；解析有终态（ready/failed）；失败可重试/全部重试；计数实时同步；KB 可新建/重命名/删除 |
| 编辑 → 发布 → 回滚 | `#/agents` → 打开 → 改字段 → 发布 | 字段进草稿、有脏检查；发布生成新版本；回滚写版本；配置文件和试运行可用 |
| 添加 → 授权 → 过期 → 恢复 | `#/connections` | 过期卡主操作是「重新授权」；OAuth 完成后列表状态真变；保存/删除/默认都落状态 |

## 布局（v5：Octop 式工作台）

> v7 已改为单栏：只有对话保留会话二级栏，其余页面统一「页头 + 页内 Tab + 内容」。本节保留为 v5 历史记录。

所有模块统一为 **三列工作台**，不再居中留白：

```
┌ 220 侧栏 ┬ 268~280 二级栏 ┬ 主内容区（自适应，最小 0）──────────────┬ 340 上下文栏 ┐
│ 21 项导航│ 列表/分组/分类  │ 页头 + 4 个 KPI + 主任务区（表格/卡片） │ 模板/健康/最近 │
└──────────┴────────────────┴───────────────────────────────────────┴───────────────┘
```

| 页面 | 二级栏 | 主区 | 上下文栏 |
|---|---|---|---|
| 任务 | 来源 / 执行器筛选 | KPI + 四桶 + 列表 + 工单详情 | 详情内嵌（审计/产物） |
| 专家 | 分组（全部/运行/空闲/停止） | KPI + 卡片网格 + 最近任务 | 模板库 / 最近会话 / 运行健康 |
| 知识库 | 库列表 + 新建入口 | KPI + 目录 chips + 文档表 | 库概览 / 摄取队列 / 检索提示 |
| 连接 | 已启用/内置/自定义 MCP | KPI + 连接器卡片 | 授权健康 / 最近使用 / 说明 |
| 自动化 | 全部/启用/暂停 | KPI + 任务表 | 最近执行 / 即将运行 |
| 用量 | 视图 + 时间范围 | KPI + 图表 + 明细表 | 成本构成 / 口径 |
| 扩展/通道/ACP/工作台 | 分类/平台/Runner | KPI + 表/卡片 | 说明与最近记录 |

- 页宽不再固定，内容随视口拉伸（`.work-grid` 在 ≤1400px 自动折叠为单列 + 横向卡片）。
- 每个页面至少 4 个 KPI，主区与上下文栏保持等高视觉重心，避免"上方一行、下方全空"。
- 二级导航统一放在左侧，页头不再叠加 Tab（避免三层导航）。

## 真正可点的交互（v4 新增/修复）

- **任务**：对话内任务卡建单；批准/拒绝/本会话允许；追加预算解除阻塞；停止/重试/重发；详情按状态给动作；每次决策写任务线 + 审计。
- **收件箱**：已读 ≠ 决策；勾选后可批量批准/拒绝（带确认）；提问行内回答；失败可重试；稍后提醒写事件。
- **知识库**：新建/重命名/删除 KB；真实文件名上传；解析完成后自动 ready；失败「重试 / 全部重试」；删除同步计数；目录树真实筛选；检索显示分数/耗时/ACL；设置可保存/取消。
- **专家**：字段级草稿与脏检查；保存草稿 / 发布新版本 / 回滚；配置文件逐个编辑保存；新建文件；导入/导出；试运行开沙箱会话；复制/删除。
- **连接器**：添加/保存/删除/设为默认；过期卡「重新授权」；OAuth 三步完成后列表真变。
- **自动化 / 通道 / ACP**：全部改为状态驱动，支持新增、编辑、启停、执行、删除与空态。
- **权限**：切换管理员/成员/只读审计；写操作按 `ACTION_PERM` 禁用并拦截点击。
- **错误与载态**：按钮 loading 会恢复；表格失败可重试；列表/目录/搜索均有空态。
- **无障碍**：弹窗 `role=dialog` + X + Esc + 初始焦点；开关 `role=switch`；toast 可读；键盘可达。
- **移动端**：任务/收件箱详情改为全屏层（可返回）；底部导航含「更多」。

## 与 Octop 的关系

- 外壳尺寸、用户菜单、页面骨架、配置页组织方式对齐 Octop；配色名称与预设对齐 `header.palette.*`。
- v7 起按模块参考它的布局与交互（对话/专家/自动化/Token 统计/个性化），配色仍是 PolyOpus 自己的；对照表见 [`docs/52`](../docs/52-模块布局与交互对齐规范.md)。
- 导航按 `04` + `52` 为 **四组 21 项**：Octop 的 19 项子页直接升为一级入口；个人设置仍从账户菜单进入。

## 边界

数据写死在前端状态里，刷新即复位；流式是定时器；附件/OAuth/云主机/远程桌面为演示实现；无后端。原型用于确认信息架构与交互闭环，不是像素级视觉稿。
